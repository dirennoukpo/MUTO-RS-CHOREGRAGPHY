SUPPORT & TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

❓ Common Issues & Solutions:

Issue: "Makefile:XX: *** missing separator"
→ Check recipe indentation: grep "^    " make/*.mk
→ All TAB characters should be literal, not spaces

Issue: Docker build fails on ARM64
→ Install QEMU: docker run --rm --privileged docker/binfmt:latest
→ Retry build

Issue: SSH provisioning fails
→ Verify connection: ssh -v pi@robot.local
→ Check SSH keys: ssh-keygen -t ed25519
→ Test: ssh-copy-id pi@robot.local

Issue: Container won't start
→ Check logs: docker compose logs -f
→ Check .env files: grep -v "^#\|^$" config/.env.muto_rs
→ Test image: docker run -it muto-rs-robot:latest bash

Issue: Tailscale not connecting
→ Verify daemon: sudo systemctl status tailscaled
→ Check auth key: echo $TS_AUTHKEY
→ Monitor: tailscale status

More help: See QUICK_REFERENCE.md for detailed debugging

LESSONS LEARNED & BEST PRACTICES
════════════════════════════════════════════════════════════════════════════

1. Make Indentation Crisis
   → Recipe lines MUST use literal TAB character, never SPACE
   → Can be broken by copy-paste or auto-formatting
   → Verify: cat -A make/*.mk | grep "^    "

2. Shebang Singularity
   → Only one #!/bin/bash per script
   → Header comments must come AFTER shebang
   → Prevents shell interpreter confusion

3. Safe Includes
   → Use `-include` for optional files (build won't fail if missing)
   → Use `include` only for mandatory files
   → Better for CI/CD environments

4. Docker Differentiation
   → Production: Strict mode (fail fast)
   → Development: Permissive mode (helpful diagnostics)
   → Different error handling and logging strategies

5. Automated Provisioning
   → Reduces manual steps and human error
   → Improves reproducibility across environments
   → Scripts should be idempotent where possible
