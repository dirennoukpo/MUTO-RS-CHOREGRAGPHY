# muto_ws

## Description
ROS 2 workspace for the MUTO-RS project. It contains the source packages, build outputs, installed artifacts, and build logs produced by Colcon.

The workspace is designed to build the robot bringup stack, the robot description, and the policy inference node as a single coherent environment.

## Key Files
- [src/muto_bringup/README.md](src/muto_bringup/README.md): bringup and low-level hardware stack.
- [src/muto_description/README.md](src/muto_description/README.md): robot model, meshes, and controller configuration.
- [src/muto_policy/README.md](src/muto_policy/README.md): ONNX policy node.
- [src/scripts/README.md](src/scripts/README.md): helper scripts.
- `build/`, `install/`, `log/`: Colcon-generated directories.

## Usage / Examples
Build the complete workspace:

```bash
cd muto_ws
colcon build
source install/setup.bash
```

Launch the robot stack after sourcing the workspace:

```bash
ros2 launch muto_bringup bringup.launch.py
```

## Technical Notes
- `src/muto_description` provides the URDF and controller configuration consumed by the bringup launch.
- `src/muto_bringup` contains the `ros2_control` hardware plugin and the low-level serial stack.
- `src/muto_policy` expects ONNX Runtime to be available at build time, with the default CMake lookup pointing to `/usr/local`.
- The `build/`, `install/`, and `log/` directories are generated artifacts and can be regenerated by Colcon.
