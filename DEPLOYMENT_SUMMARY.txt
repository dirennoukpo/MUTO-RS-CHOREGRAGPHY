🚀 QUICK START GUIDE
════════════════════════════════════════════════════════════════════════════

FOR LOCAL DEVELOPMENT:

  1. Review configuration:
     cat config/.env.workstation

  2. Build development image:
     make build ENV=workstation PLATFORM=linux/amd64

  3. Start development environment:
     make workstation-deploy

  4. View running containers:
     make workstation-status

FOR ROBOT DEPLOYMENT:

  1. Prepare Raspberry Pi 5:
     ssh pi@robot.local
     # Get IP address for provisioning

  2. Provision robot (automated):
     make provision-muto-rs SSH_HOST=pi@192.168.1.100

  3. Build production image:
     make build ENV=muto-rs PLATFORM=linux/arm64

  4. Transfer to robot:
     make send-image SSH_HOST=pi@192.168.1.100 ENV=muto-rs

  5. Deploy on robot:
     make muto-rs-deploy SSH_HOST=pi@192.168.1.100

  6. Monitor robot:
     make muto-rs-logs SSH_HOST=pi@192.168.1.100
     make muto-rs-status SSH_HOST=pi@192.168.1.100

🎓 LESSONS LEARNED
════════════════════════════════════════════════════════════════════════════

1. Makefile TAB Character: Recipe lines MUST use literal TAB, not spaces.
   Verification: grep "^    " make/*.mk should return empty results.

2. Shebang Singularity: Only one #!/bin/bash per script, no interleaving.
   Prevents shell interpreter confusion.

3. Safe Include Syntax: Use -include (with leading dash) for optional files.
   Better for CI/CD pipelines that may not have all configs.

4. Docker Differentiation: Production containers should be strict
   (fail fast), development should be permissive (helpful diagnostics).

5. Automated Provisioning: Reduces manual steps, improves reproducibility.
   Scripts should be idempotent where possible.

❓ FAQ & TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

Q: My build fails with "missing separator" error
A: Check Makefile recipe lines are indented with TAB, not spaces.
   Use: grep "^    " make/*.mk

Q: SSH provisioning fails
A: Verify robot is reachable: ping pi@robot.local
   Check SSH key: ssh-keygen -t ed25519
   Test connection: ssh -v pi@robot.local

Q: Docker build hangs on ARM64
A: Docker buildx may need QEMU emulation enabled
   Try: docker run --rm --privileged docker/binfmt:latest

Q: Container won't start
A: Check logs: docker compose logs -f
   Verify environment variables: cat config/.env.*
   Test locally first with workstation image

Q: Tailscale connection not working
A: Verify authkey in config/.env files
   Check Tailscale daemon: tailscale status
   Review VPN settings: tailscale ip
